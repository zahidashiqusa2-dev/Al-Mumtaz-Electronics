1. WHAT THIS SYSTEM CREATES & DOES (END-TO-END OVERVIEW)
================================================================================
This project is a complete, production-grade Full-Stack E-Commerce Storefront,
Protected Admin Console (/admin), Media CDN/SQLite Image Server, and 24/7
Two-Way @whiskeysockets/baileys WhatsApp Automation & Order Verification Engine.

It consists of two synchronized Node.js applications inside one repository:
1) ROOT APPLICATION (/server.js + /public + /lib):
   - Hosts the public customer e-commerce storefront (/ and /track/:orderId).
   - Hosts the isolated, password-protected ProfitPulse-inspired Admin Console (/admin).
   - Runs a built-in SQLite database (node:sqlite) with WAL mode that automatically
     resolves writable storage paths (/app/data, custom DATA_DIR, or /tmp fallback
     so Cloud Run / containerized deployments never crash with EACCES).
   - Stores uploaded product images in Cloudinary (when Cloudinary_URI is set)
     or directly in SQLite binary blobs served via GET /api/images/:id.
   - Provides a complete REST API (/api/*) for products, categories, multi-variant
     pricing, cart totals calculation, COD checkout, live order tracking, analytics,
     and two-way WhatsApp webhook & session-backup bridges.
   - Includes a built-in Baileys WhatsApp engine AND a seamless HTTP bridge to
     forward outbound/inbound WhatsApp traffic to the 24/7 Railway bot service.

2) STANDALONE 24/7 RAILWAY WHATSAPP BOT (/Railway folder):
   - Dedicated microservice designed to be deployed on Railway.app (with Root
     Directory set to `Railway`).
   - Maintains a non-stop 24/7 @whiskeysockets/baileys WhatsApp Web socket.
   - Supports ZERO-VOLUME (Variables-Only) deployment: even without mounting a
     Railway Volume, it automatically backs up and restores `creds.json`, session
     tokens, and Signal encryption key files to the main AI Studio website via
     `/api/bridge/wa-auth/:sessionId` (and optionally PostgreSQL/Supabase).
   - Fetches live categories, products, variant prices, and order statuses from
     the main website in real time via `SITE_API_URL` + `API_SECRET_KEY`.
